## 📌 Featured Projects

### 🛍️ [Digital Catalog — Commercial Project](https://github.com/RafaelVn1808/CatalogoApi)

**Commercial project built on demand and sold to end client, currently live in production on the client's own domain.**

Fullstack REST API for physical store catalogs with multi-store product management, branch-level inventory, categories, image upload, and spreadsheet import (CSV/XLSX/XLS).

- **Stack:** C# / .NET 10, ASP.NET Core Web API, EF Core + PostgreSQL (Supabase), React 18 + TypeScript + Vite, Nginx, Docker Compose
- **Security:** JWT with refresh token, BCrypt, role-based authorization, rate limiting (100 req/min per IP/user)
- **Infrastructure:** Multi-stage Dockerfile with non-root user, Vercel (frontend) + Render (API) + Supabase (DB/storage)
- **Quality:** xUnit tests with EF Core InMemory, global exception middleware, request logging, health checks
- 🔗 **Live demo:** [grupobompreco.com.br](https://grupobompreco.com.br)

### 💳 [Expense Management System](https://github.com/RafaelVn1808/ExpenseManagement)

Comprehensive REST API for expense tracking with identity management and automated testing.

- **Stack:** ASP.NET Core Web API, EF Core, AutoMapper, Swagger
- **Security:** JWT with refresh token, ASP.NET Identity, role-based access control
- **Infrastructure:** Docker Compose (API + Frontend MVC), Supabase (DB/storage), Oracle Cloud Free Tier with custom domain, Cloudflare CDN/SSL
- **Testing:** xUnit + Moq
- 🔗 **Live demo:** [expense.almeidadev.com.br](https://expense.almeidadev.com.br)
